# BlkSpace `v0.1.0-yard`

**First student-facing Yard release**  
**Product mark:** BlkSpace (orange capital **B**) · **Coin ticker:** BKSPC (gated)  
**Tag date:** 2026-08-02  

---

## What this is

| | Yard (`v0.1.0-yard`) |
|--|----------------------|
| Audience | HBCU students on everyday laptops (Tier 0, 4–8 GB RAM) |
| Build | Tauri **without** default Iroh mesh (`--no-default-features`) |
| Frontend | Tier 0 lite boot where CI sets it |
| Soft currency | WeixBucks (WB) |
| Settlement | **BKSPC** (BlkSpace Coin) — **not** mainnet rights in this tag |

**Not** `BlkSpace-Full` (Iroh mesh / lab machines).

## Included (campus amalgamation MVP)

- Guest browse + free account wizard + recovery phrase  
- Feed · yards · MyYard · search  
- WeixBucks wallet (local) · Yard Cred withdraw gate  
- ProjectConnect (orgs, opportunities, talent board, faculty broadcast)  
- Yard Sale + **2-party escrow** · fashion/digital listing types  
- Events · capacity · club exclusive · guest list / check-in  
- Clubs · reading circles · tournaments (no live stream)  
- Studio portfolio · client free/paid all-in-one delivery · export  
- Turso embedded DB · multi-OS CI path  
- Brand: orange capital **B** wordmark on GitHub + app chrome
