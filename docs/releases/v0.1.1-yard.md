# BlkSpace `v0.1.1-yard`

**Yard patch** — Join / recovery phrase works on the shipped SPA bundle.  
**Product mark:** BlkSpace · **Coin ticker:** BKSPC (gated)  
**Tag date:** 2026-08-13  

---

## Why this tag

`v0.1.0-yard` Vite / emergency bundles had no Node `Buffer`. Creating a free account threw **`Buffer is not defined`** (bip39 recovery phrase). Device B student path 1–6 passes after this polyfill.

| | Yard (`v0.1.1-yard`) |
|--|----------------------|
| Audience | HBCU students on everyday laptops (Tier 0, 4–8 GB RAM) |
| Build | Tauri **without** default Iroh (`--no-default-features`) |
| Product version | **0.1.1** |
| Fix | `public/buffer-polyfill.js` loaded before app modules |

**Not** `BlkSpace-Full` (Iroh mesh / lab machines).
