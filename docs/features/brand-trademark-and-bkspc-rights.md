## Naming stack (locked)

| Layer | Canonical string | Where it appears |
|-------|------------------|------------------|
| **Product / app / UI** | **BlkSpace** | Nav, welcome, README title, installers, GitHub repo `BlkSpace` |
| **Coin / settlement ticker** | **BKSPC** | Wallet settlement, Solana, pump.fun *if* launched, investor token column |
| **Coin long name** | **BlkSpace Coin** | Tokenomics, legal-facing settlement copy |
| **Soft credits** | WeixBucks (**WB**) | Earn/spend, marketplace, escrow — **not** the product mark |

### Why both

- **BlkSpace** is the **best UI product mark** you want protected (campus social amalgamation).  
- **BKSPC** is the **short ticker** for settlement rights / on-chain utility when gated launch is allowed.  
- GitHub canonical: [`https://github.com/er1cbrown/BlkSpace`](https://github.com/er1cbrown/BlkSpace) — keep **B** and **S** casing in the repo name.

### What not to do

- Do **not** rename the whole product to “BKSPC” in the UI (that confuses trademark path with ticker).  
- Do **not** market mainnet BKSPC as “already live rights for everyone” without Cred gates + counsel.  
- Do **not** use alternate spellings (`blkspace`, `BLKSPACE`, `Bkspace`) in public chrome.
