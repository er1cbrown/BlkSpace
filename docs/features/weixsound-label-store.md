# WeixSound label store

**Date:** 2026-10-28
**Status:** Decision. Model A. Perpetuals stay off.
**Label:** Bermuda Boyz Records
**Product:** WeixSound

WeixSound is the record store. A student plays a release free and buys one numbered copy with earned WeixBucks. The stream is the listening room. The sale is the disc. One master audio file backs every format. The format is the sleeve, the length, and the edition.

| Format | What the buyer holds |
|---|---|
| Single / vinyl | One track, a small edition |
| EP | A short set |
| Mixtape | Up to 12 tracks |
| Album / LP | The full set, one edition |
| CD | The same master, a different sleeve and copy count |

The label page groups those releases and prints the split before anyone pays. The yard keeps 5 percent. The rest goes to the people named on the sleeve. A verse or Logos set can sit in the yard catalog. It does not leave as a public disc.

## Decision

Customizable means the label sets the release. Edition size from 1 to 100, format, WeixBucks price, yard-only or public link, and whether a Solana receipt is written after the sale. Those switches change the disc. They do not add leverage.

A perpetual desk stays specified and off, which is the written Model A choice. Turning it on makes BlkSpace a derivatives operator: oracle, insurance fund, liquidation, and a license question. Students on the free stream never get that screen. WeixBucks cannot be the thing being leveraged. The token policy already lists perpetuals as a non-goal.

The robust distributor is the catalog plus the file on R2 plus an https link the label chooses to Audius, SoundCloud, Bandcamp, or Tidal. The chain publishes the receipt of a copy that already sold.

Solana carries that receipt because BKSPC already settles there. Ethereum holds the closed BI9 book. BI9 does not price a disc. Neither chain runs a perpetual inside the student app.
